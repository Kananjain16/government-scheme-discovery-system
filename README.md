# Government Scheme Discovery System

An AI-powered platform that helps users discover relevant government schemes based on their requirements and eligibility.

### Features
- Government scheme information and eligibility details.
- Document chunking and embedding generation.
- Retrieval-Augmented Generation (RAG) for context-aware responses.
- Gemini API integration for AI-generated answers.

### Tech Stack
- Python
- MySQL
- HTML, CSS, JavaScript
- Sentence Transformers
- Google Gemini API

### Purpose
To make government scheme information easier to discover and understand through AI-powered information retrieval.

USE THIS FOR INSTALLING 
pip install package-name
pip freeze > backend/requirements.txt

TO START THE ENV
.\venv\Scripts\Activate.ps1

TO START THE FRONTEND
cd frontend
